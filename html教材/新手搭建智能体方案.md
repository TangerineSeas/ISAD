# 新手智能体搭建4套方案（由易到难，优先推荐顺序）
> 新手核心原则：**先零代码跑通MVP，再逐步接触低代码，最后写代码理解原理**，不要一上来就啃框架

## 方案1：纯零代码（完全不用写代码，小白首选）
✅ **代表：Coze（扣子）、文心智能体、豆包智能体**
- 上手难度：⭐
- 适合人群：学生、运营、教师，只想快速做助手、知识库bot、文案助手、学习助手
- 核心能力：写人设提示词、上传知识库、拖拽工作流、插件市场直接调用（联网搜索、绘图、表格），一键发布到豆包、飞书、抖音小程序、网页嵌入
- 优点：国内平台、中文友好、免费额度充足，10分钟就能做出可用智能体；生态打通，分发简单
- 局限：闭源，复杂业务逻辑、高敏感内网数据不适合；复杂多Agent编排能力有限
- 典型案例：档案文献问答助手、课程答疑bot、顺风车话术生成器

## 方案2：低代码开源平台（兼顾可控性+低门槛，新手进阶首选）
✅ **代表：Dify、FastGPT、RAGFlow**
- 上手难度：⭐⭐
- 适合人群：想做知识库问答、私有化部署、有文档检索需求；愿意简单了解Docker一键部署
- Dify：全能型，Agent工作流、RAG、API、日志、LLMOps全套；云端版直接用，也可以本地私有化，适合教学、科研、内部知识库
- FastGPT：主打轻量化RAG知识库，中文文档友好，适合论文、规章、教材问答；部署简单，检索参数可调
- RAGFlow：PDF、扫描件、古籍、档案类复杂文档解析更强，适合文史、档案、地方志这类高精度文档场景
- 优点：开源、数据自己掌控，支持换任意大模型（豆包、DeepSeek、通义千问）
- 局限：自部署需要服务器，云端版有额度限制，术语比Coze多一点

## 方案3：可视化自动化+Agent（业务联动，适合有办公自动化需求）
✅ **代表：n8n、Flowise**
- 上手难度：⭐⭐⭐
- 适合人群：需要智能体对接表格、邮件、表单、数据库、网盘，做自动化任务（自动汇总文献、定时抓取信息、自动整理问卷）
- 玩法：拖拽节点，把大模型节点、http请求、文件读写、定时触发器串起来，做ReAct智能体循环
- 优点：集成能力极强，适合科研数据采集、业务流程自动化；支持搭配Ollama本地模型
- 局限：偏自动化，纯对话体验不如上面两个平台，配置项多

## 方案4：代码框架（理解底层原理，适合想学习Agent开发）
✅ **代表：LangChain / LlamaIndex → LangGraph（进阶）**
- 上手难度：⭐⭐⭐⭐⭐
- 适合人群：会Python，想弄懂ReAct、工具调用、记忆、多智能体协作原理
- 新手路线：先用LangChain写极简ReAct智能体（联网+计算器），再学LangGraph做状态流转、多Agent分工；本地搭配Ollama跑开源模型，不消耗API费用
- 优点：完全自由，自定义逻辑、自定义工具、自定义记忆
- 局限：需要Python基础，调试成本高，新手容易卡在循环、token、工具调用报错

# 新手选型一句话速查
- 只想快速做一个教学/答疑助手、给学生用、发微信小程序：**Coze（扣子）**
- 档案、古籍、论文、教材知识库，希望数据不外流：**FastGPT / RAGFlow**
- 课程实验、信息系统课程作业，需要私有化、完整LLMOps：**Dify**
- 自动爬取文献、同步表格、定时任务：**n8n**
- 想学习Agent底层原理、写代码：**LangChain + Ollama本地模型**

# 新手入门推荐路线（最稳）
1. 先用Coze，做第一个智能体：提示词+知识库，跑通测试、发布
2. 再试Dify，理解RAG检索、分段、重排这些核心概念
3. 有Python基础，再手写极简LangChain Agent，看懂ReAct循环
4. 最后再上n8n做自动化，或者LangGraph做多智能体



如果需要，可以找一份**新手第一个智能体的提示词模板**，或者直接获取Dify/Coze的档案类问答智能体配置清单。
